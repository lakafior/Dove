Plugins

Plugins add sources to Dove's search: covers and details for books, audiobooks and games, and files from libraries without an official API. Dove ships with none. You add a plugin repository by its address, the same way you add a Stremio addon or an indexer, and install the plugins you want from it.

Adding a repository

  1. In Dove, open Settings › Search and metadata › Plugins › Add repository.
  2. Paste the repository's address (it ends in index.json).
  3. Install a plugin. Dove shows the sites it may reach first, then asks for its settings, if it has any.

Plugins run on your iPhone or Mac, in a JavaScript sandbox with no access to your files, your services' keys, other plugins or Dove's data. A plugin can reach only the sites its listing names. Dove installs a script only when it matches the checksum in the repository's index, and updates only when you tap Update.

Made a repository?

Anyone can publish one: a plugin is a single JavaScript file, and a repository is an index.json listing them, hosted anywhere over HTTPS. The contract is Dove's plugin API; the Dove plugins repository is a working example with a build script.

To have yours listed here, write to dove@smigi.net or open an issue on GitHub with its address and a line on what it does. This page lists repositories whose plugins reach sources you are allowed to use: metadata, public-domain and open libraries, your own servers and accounts.

Plugins are written by their authors, not by the Dove developer, and reach sites that Dove does not control. Check what a plugin reaches before you install it, and use it only with content you have the right to access.
