# What was built, as it was built

The record of Dove's implementation: every decision, dead end and API quirk found on the way, kept
verbatim as it was written down at the time. It is reference to grep, not a document to read start to
finish, and it is deliberately not rewritten: the detail is why it is here.

For the current state — what is done, what is left, what was decided against — see
[roadmap.md](roadmap.md). The Mac plan is [macos.md](macos.md), the plugin API [plugins.md](plugins.md).

Dates are the day the work landed. Items struck through were later removed or dropped; the note says why.

It seeds, so private trackers' torrents go only there: `TorrentFile.isPrivate` reads `info.private` from the `.torrent`, `LibraryBackend.seedsTorrents` (true only for Debrid-Link) gates `supports(_:)`, so the router never offers or falls through to another service, and RD/TorBox/Offcloud refuse such a file even when picked by hand (`refusePrivateTorrent`, `BackendError.privateTorrent`). Seeding stats: `LibraryItem.seeding` (`uploadRatio`, status 8 = seeding, `uploadSpeed`, `peersConnected` from `seedbox/list`, no extra calls); release rows and the item screen show it (not posters: it breaks the grid) (red < 0.5, orange < 1, green ≥ 1). Torznab rows keep their `.torrent` link even with an info hash, and adds prefer it over the magnet (the flag and the passkey are only in the file).
- [x] TorBox plan and seeding (2026-10-14): `TorBoxPlan` from `user/me` `plan` (0 Free, 1 Essential, 2 Pro, 3 Standard), overridable in Settings › TorBox › Plan (`TorBoxPlanSetting`, Keychain `torBoxPlan`, refreshed by `AppModel.refreshAccounts`). Pro includes Usenet: TorBox Usenet follows the plan unless turned off (`torBoxUsenet` "0"), and is off on other known plans. Paid plans seed (Essential 24 h, Standard 14 days, Pro 30 days), so TorBox can take private trackers' torrents: `PrivateTrackerTarget` (Settings › Debrid › Private trackers, shown when Debrid-Link and a seeding TorBox are both set up; Automatic = Debrid-Link, else TorBox) sets each backend's `takesPrivateTorrents` (renamed from `seedsTorrents`). TorBox adds those with `seed=2`; `add(_:category:privateTracker:)` carries an indexer's "private" to the service. Seeding stats from `mylist` (`ratio`, `upload_speed`, `peers`, state `uploading`), shown only while seeding or with ratio > 0 (cached torrents are 0). Fixture-tested, checked live by the owner (2026-10-20).

- [x] Source rows: `StreamGroup` merges one release across services (per-service ⚡ cache), `ReleaseParser` fills traits from names; filters (cached only, resolution); Apple TV warnings (AV1, TrueHD Atmos)
- [x] Whole season / whole series: ask for the first episode, keep packs (`PackScope`), add without a file index
- [x] Search results filter: all / movies / series
- [x] `CacheChecker`: TorBox `checkcached` and Offcloud `cache/info` mark rows by info hash (RD has no endpoint); AIOStreams password is validated (`GET /api/v1/user`) before it is saved
- [x] `SourceFilter`: resolution, source, codec, HDR/DV/SDR, audio, language, cached-on; sort by size; Apple TV friendly; persisted
- [x] AIOStreams config variant (`&v=`, also read from `/v/<id>/` in the manifest URL) so Dove can get an unfiltered list while Stremio keeps the filtered one
- [x] Source origin (2026-10-14): every `StreamCandidate` says who found it (`provider`: AIOStreams, the addon's manifest name, Dove's indexer; `addon` inside AIOStreams; `tracker`: Jackett `jackettindexer`, Prowlarr `prowlarrindexer`, AIOStreams `indexer` (may be `a,b,c`), Torrentio's `⚙️` line), `isPrivate` (Jackett `<type>` public/semi-private/private, Prowlarr `type`, AIOStreams `private`), `seeders` (also AIOStreams and Torrentio `👤`), `published` (`pubDate`/`usenetdate`, AIOStreams `age` in hours). Rows show `SourceOriginLine`; `SourceFilter` filters by type, tracker access, found by, tracker/indexer and sorts by seeders or newest; Search › Other has its own session filter. An indexer's "private" also limits adds to seeding services (`BackendRouter.forPrivateTracker`), even for magnets.
- [x] Source ranking: sort "Recommended" (`SourceRanking`: usable on the user's debrids → Apple TV friendly → ladder → resolution, HDR, source, audio → not refused by RD (only a tie-breaker since 2026-10-16: with another debrid Automatic loses one quick try) → size); RD name warning on rows. Ladder (2026-10-16, `SourceRanking.Tier`): ready (cached on a user's service, or Usenet on any service) → direct file links (2026-10-19) → uncached public → uncached private → limited (header/DASH links); quality sorts within a rung (a first try with Usenet as its own rung below cached sank 2160p DV NZBs under cached 1080p).
- [x] Private but cached (2026-10-16, `AddRoute`, `StreamGroup.route(through:)`): a private tracker's release that a torrent service of the user has cached goes there as a bare magnet, without `seedingOnly` (nothing is downloaded, the tracker never sees the passkey, ratio does not move); uncached ones go as the indexer's `.torrent` to seeding services only. "Add only to" offers both (`addTargets`). NZB and torrent candidates never share a `StreamGroup` (same release name from Usenet indexers and a private Torznab tracker used to make the Usenet row "private" and send it to Debrid-Link).
- [x] Pack completeness (`PackCompleteness`): source list estimates episodes from pack size ÷ episode size (warns only when clearly short) and series packs' seasons; library shows exact "All 9 episodes" / "Missing E04, E07" per season from files (RD/Offcloud packs: one detail call each, this title only)
- [x] TMDB (`TMDBMetadata`, user's key, Settings › Metadata): with a key it searches (`/search/multi`) and describes (seasons/episodes via `append_to_response=season/N`) before the addons, which take over on failure; library matching and posters (`w342`) go through it too. A series' episodes still come from the metadata addon when one answers (stream addons share Cinemeta/IMDb numbering; TMDB splits seasons differently for anime and some long shows); TMDB seasons only as a fallback. Library › ⋯ › Re-match all titles looks every title up again (manual choices stay; a title with no new answer keeps its old match). `en-US`, not `pl-PL`: titles must match release names.
- [x] Library: every backend in one list (`LibraryLoader`), titles with posters (`ReleaseParser.guess` → `LibraryMatcher` through the search addon, cached in `MatchStore`, manual fix), Titles / Files views, filters (services, type, status, text)
- [x] Library series screen: seasons → episodes, each matched to a file (`SeriesLayout`: scene codes, `1x02`, "Season 1" folders with "01 - Pilot", the release's season; metadata episodes show missing ones; best version first: ready → resolution → size, picker per episode). Play all / season / episode / from here as one Infuse playlist (`EpisodePlaylist`, links fetched 4 at a time); releases stay listed below for actions. Files Dove cannot place are counted and reachable from their release.

Original plan:
- `MetadataProvider` protocol; TMDB implementation (`language=pl-PL` — done as `en-US`, `/search/multi`, then `append_to_response=external_ids` for the IMDb ID). User supplies their own TMDB key.
- `StreamSource` protocol with two implementations:
  - Stremio addons: `{base}/manifest.json`, `{base}/stream/{movie|series}/{imdbId}[:{season}:{episode}].json`. Streams carry `url` (debrid-resolved → download) or `infoHash` + `fileIdx` (→ magnet → add to library).
  - AIOStreams Search API: `GET {base}/api/v1/search?type=…&id=…` with Basic Auth (uuid:password). Returns structured fields (`infoHash`, `url`, `nzbUrl`, `cached`, `service`, `size`, `parsedFile`, `folderName`, `folderSize`, `bingeGroup`). Preferred when available.
- Addon manifest URLs often embed secrets → store them in the Keychain.
- Source list sheet: one list for all types, small type icon per row (🧲 / 📰); "Episode / Whole season" toggle.
- Whole season: query `S{n}E1`, keep season packs (folder size ≫ file size, season without episode), add the torrent **without** `fileIdx`. Fallback: per-episode, preferring the same `bingeGroup`. Warn on incomplete packs (files vs TMDB episode count) and on full-series packs.

### Stage 3 — Usenet (in progress)
- [x] `NzbdavBackend` (see its doc comment): POST-form SABnzbd API (`addurl` / `addfile`, `queue` / `history`, delete), WebDAV `PROPFIND` on `/content/{category}/{job}/` (`WebDAVClient`), downloads with Basic Auth, `PlaybackLinking` URL with the login for Infuse. Checked live against a real nzbdav.
- [x] TorBox Usenet (`usenet/…` endpoints from the SDK, fixture-tested only), behind the "TorBox Usenet" toggle; NZBs route to nzbdav before TorBox
- [x] Offcloud Usenet (2026-10-14): `POST cloud` takes NZB links and `.nzb` files like any source (fixture-tested; checked live by the owner, 2026-10-22), behind the "Offcloud Usenet" toggle (`CredentialKey.offcloudUsenet`); NZBs follow the Usenet priority (`AppModel.usenetBackend`, `nzbBackends`, Move to follow it too). Offcloud NZB items cannot be reinserted or moved (no stored NZB).
- [x] Settings: nzbdav (URL, API key, WebDAV login), TorBox Usenet toggle; Indexers (Newznab + Torznab) live under Settings › Search
- [x] Dove's own Newznab indexers (`NewznabClient`, `NewznabSearch`): searched from the phone in parallel with the addons; caps once, results cached 1 h, daily hit counting and limits, same release from several indexers merged into one row
- [x] Dove's AIOStreams variant (`doveVariantScript`, modelled on AIOStreams' "Debrid Only" template): unfiltered; Usenet services off; Usenet/HTTP-only addons off by type (custom Usenet addons by `instanceId`); Usenet/HTTP stream types excluded; P2P kept (Dove adds bare info hashes to a debrid). AIOStreams spends no indexer hits on Dove's searches; Stremio keeps the base config
- [x] nzbdav library = every job folder under `/content` (folders without a history entry listed as `dav:` items, deleted with WebDAV `DELETE`, which needs nzbdav's "Enforce Read-Only" off); multi-select delete in Library → Files
- [x] Search › Other: free-text Newznab search (`NewznabQuery.text`, `t=search&cat=`) in All / Software (4000) / Music (3000) / Books (7000) / Audiobooks (3030; a subcategory filter keeps only itself, adds are marked `.audiobooks`, NZBs filed under `audiobooks`); rows are `StreamGroup`s (same torrent from several trackers = one row), torrents get ⚡ from `CacheChecker` and cached ones move up; add prefers services that have it cached, "Download only" takes every file. Movie/series searches send `cat=2000`/`5000` and drop results from other categories (indexers that ignore `cat`).
- [x] Torznab indexers (`NewznabIndexer.kind`): Jackett/Prowlarr feeds in the same list as Newznab; results are `.p2p` torrents (info hash → magnet + cache check; otherwise `torrentURL`), in movie sources and Search › Other. Checked live with the owner's Jackett (VPS, behind a Cloudflare tunnel; Jackett's Base URL override must be the https address, or its .torrent links come out as http and ATS blocks them).
- TorBox Search API (`search-api.torbox.app`, real Newznab/Torznab) is gone: DNS removed around Oct 2026, no replacement.
- Library shows nzbdav items like any other service (filter by service); show queue/history; failed jobs (missing articles) offer "try next NZB". Done: Reinsert retries a failed job (InfiniDysk `mode=retry`, else from its stored NZB), Move to sends it to TorBox Usenet. Queue/history (2026-10-20): covered by the Library and Downloads › On services; nzbdav itself downloads nothing (it mounts the NZB and streams), so a job sits in its queue for seconds and has no speed or ETA worth showing. Speed and time left were added for the services that really download (uncached torrents): `LibraryItem.downloadSpeed` (Real-Debrid `speed`, TorBox `download_speed`, AllDebrid and Debrid-Link `downloadSpeed`; 0 = none) and `secondsLeft` (size × what is left ÷ speed), shown on On services rows ("5 MB/s · about 10 min left"). Fixture-tested (AllDebrid); TorBox's field name from its SDK; checked on a real downloading torrent by the owner (2026-10-22).

### Onboarding (2026-10-27)

A step whose setting is already there (synced through iCloud Keychain) is marked `alreadySet` and can be skipped. `SetupWizard` (App/Dove/Features/Settings, compiled for both apps) embeds each page's own view (`SettingsPage.destination`) with Back / Skip / Next; nothing is rebuilt and no setting was added. The one new value is device-local `setupFinished` (UserDefaults), set by Done or Skip setup. ### Update check (2026-10-27)

Mac only: iOS updates come through AltStore. `UpdateChecker` (DoveKit, tested) asks `https://api.github.com/repos/lakafior/Dove/releases/latest` (unauthenticated: 60 requests an hour per IP; `Accept: application/vnd.github+json`, `X-GitHub-Api-Version: 2022-11-28`, a User-Agent, which GitHub requires). That endpoint skips drafts and prereleases; 404 means no release yet (up to date), 403/429 the rate limit. `AppVersion` compares numerically per component and ignores a leading `v`, so the tag `v1.0.0` (what `release.yml` checks against `MARKETING_VERSION`) matches `1.0.0`. The DMG is the first asset ending in `.dmg`, else the release page. `UpdateModel` (DoveAppCore): `checkAutomatically()` from `MacRootView` at most once in 24 h (`updateLastCheck`), quiet on errors, honours `updateSkippedTag`; `checkNow()` from Dove › Check for Updates… reports "up to date" and errors too. Download only opens the URL; nothing is fetched or installed by Dove. Written by a delegated Codex job, reviewed and tidied by hand.

### Demo mode and screenshots (2026-10-27/29)

`-demo` at launch, Debug builds only (`DemoMode.isActive` is `#if DEBUG`; Release compiles every demo file out):
Dove shows a made-up TorBox account of public-domain works so README, the website and the AltStore listing get
screenshots without anyone's real library. `scripts/screenshots.sh` runs two UI test targets (`DoveUITests` on a
fresh "Dove Screenshots" simulator, iPhone 18 Pro Max 6.9" at native 1320×2868, status bar overridden to 9:41;
`DoveMacUITests` on this Mac, window screenshots) and copies the PNGs to `docs/screenshots/`. The tests only attach
each screenshot under its file name (`Screenshot.save`); the script exports them from the result bundles with
`xcrun xcresulttool export attachments` (names come back as `<name>_0_<UUID>.png` in `manifest.json`). Writing files
from the test failed on the Mac: the UI test runner is sandboxed (`NSCocoaErrorDomain 513`). The result bundles also
hold screen recordings of the whole display, so they stay in a temporary folder. One launch per screen, so one failure
leaves the rest. Once a "WidgetRenderer_Default quit unexpectedly" system dialog (not Dove's) landed on the Mac window
screenshot: look at the images before committing them. AVAudioFile cannot write MP3, so the demo's tone files are WAV
whatever the release's extension.

Isolation, because on the Mac the demo runs in the real app's container (same bundle ID):
- `DoveStorage` (DoveKit): `applicationSupport`, `caches` and `defaults` replace every `URL.applicationSupportDirectory/Dove`,
  `cachesDirectory/Dove` and `UserDefaults.standard`; in demo mode a `tmp/DoveDemo` folder (wiped per launch) and the
  suite `net.smigi.dove.demo`. SwiftUI's `@AppStorage` follows through `.defaultAppStorage(DoveStorage.defaults)` on
  every scene (iOS window, Mac window, menu bar extra, Settings), plus an explicit `store:` on the Mac app's own one.
- `KeychainStore.inMemory` / `.demo`: `SharedConfiguration.keychain()` returns the in-memory store, seeded with a TorBox
  key (so Settings shows it set up) and the demo addon. `SharedConfiguration.backends` answers `[DemoBackend()]`.
- `appGroupContainer` is nil: no widget snapshot, `kinds.json` in the demo folder.
- `DemoPlatform` wraps the app's `AppPlatform`: screens, links and artwork pass through; Files/Finder location,
  Spotlight, widgets, Live Activity and Siri suggestions are no-ops. `SpotlightIndex.describe` marks screens not eligible.
- Downloads use an ephemeral session (the real background session's identifier would reattach, and `reconnect` cancel,
  the real app's tasks) and skip `reconnect`; `DownloadManager.showDemo` sets frozen records. No iCloud Drive, no
  notification prompt or posts (`LocalNotifications`), `setupFinished` true (the wizard still opens from Settings).

Network: `DemoURLProtocol` is registered for the run (`URLProtocol.registerClass`, reaches `URLSession.shared` and
so every default transport in the package) and answers every http(s) request from `DemoServer`, except Wikimedia's
image hosts (`commons`, `upload`, `thumb.wikimedia.org`), which load for real. Simpler than threading a transport
through `AppModel`, and nothing in demo mode can reach a real service by accident. `DemoServer` is a Stremio addon at
`https://demo.dove.invalid/` ("Public Domain": catalog with search, meta, streams for six films and four Beverly
Hillbillies season 1 episodes known to be public domain); stream text is Torrentio-shaped (👤 💾 ⚙️, `[TB+]`), and
info hashes ending in `ca` are what `DemoBackend.cachedHashes` reports cached (the ⚡). Posters and covers are
`commons.wikimedia.org/wiki/Special:FilePath/<file>?width=500` links (redirects to the thumbnail; every file checked
"Public domain" through the Commons API).

Matches: `AppModel.startDemo` writes the posters, book covers and albums with the public `setMatch`/`setBookMatch`/
`setAlbumMatch` under each item's guess key, in a task `LibraryModel.start` awaits (`demoSeeding`), so the matcher never
looks anything up. Films would also match through the demo addon; books and albums would otherwise ask Open Library.

`-demo -demoAudiobook` opens the player on the demo LibriVox Sherlock Holmes; in demo mode `AudiobookDemo` serves
generated tone files for any demo audiobook, so Play works from the library too.
